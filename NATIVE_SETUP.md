# Native App Setup Guide

This project uses [Capacitor](https://capacitorjs.com) to wrap the React app
into a native iOS and Android app with real haptic feedback.

## Prerequisites

| Tool | Required for |
|------|-------------|
| Node.js 18+ | Everything |
| Xcode 15+ | iOS build |
| Android Studio | Android build |
| Apple Developer account ($99/yr) | App Store submission |
| Google Play account ($25 one-time) | Play Store submission |

---

## Step 1 — Install dependencies

```bash
npm install
```

---

## Step 2 — Deploy your backend

The native app needs a publicly reachable WebSocket server.

**Deploy to Railway (recommended)**:
1. Push this repo to GitHub
2. Go to [railway.app](https://railway.app) → New Project → from GitHub
3. Set environment variable: `NODE_ENV=production`
4. Set start command: `npm run build && node dist/server.js`
5. Copy the Railway URL (e.g. `morse-vibe-production.up.railway.app`)

---

## Step 3 — Set your server URL

Open `src/App.tsx` and find this line (around line 100):

```ts
return 'wss://your-railway-app.up.railway.app';
```

Replace with your actual Railway URL:

```ts
return 'wss://morse-vibe-production.up.railway.app';
```

---

## Step 4 — Initialise Capacitor

Run this **once** to scaffold the native projects:

```bash
npx cap init "Morse Vibe" "com.morsevibe.app" --web-dir dist
npx cap add ios
npx cap add android
```

---

## Step 5 — Build and sync

Every time you change the React code, run:

```bash
npm run cap:sync
# equivalent to: npm run build && npx cap sync
```

---

## Step 6 — Open in Xcode / Android Studio

```bash
# iOS
npm run cap:ios
# opens Xcode — select a simulator or device and press Run

# Android
npm run cap:android
# opens Android Studio — select a device and press Run
```

---

## Live reload during development

Instead of rebuilding every change, use live reload:

```bash
# Make sure your dev server is running first
npm run dev

# Then in another terminal:
npx cap run android --livereload --external
# or
npx cap run ios --livereload --external
```

---

## Submitting to app stores

### iOS (App Store)
1. In Xcode, set your Team (Apple Developer account)
2. Change the bundle ID from `com.morsevibe.app` to something unique
3. Product → Archive → Distribute App → App Store Connect

### Android (Play Store)
1. In Android Studio, Build → Generate Signed Bundle / APK
2. Create a keystore (keep it safe — you need it for every update)
3. Upload the `.aab` file to Google Play Console

## Haptics notes

| Platform | Haptic API used |
|----------|----------------|
| iOS (native) | CoreHaptics via `@capacitor/haptics` — full support |
| Android (native) | `VibrationEffect` via `@capacitor/haptics` — full support |
| Android Chrome (web) | `navigator.vibrate` — works |
| iOS Safari (web) | `navigator.vibrate` — **silently ignored by Apple** |

This is why the native app matters for iOS users — web vibration simply
doesn't work in any iOS browser. The native build bypasses this entirely.

## Project structure

```
├── capacitor.config.ts     # Capacitor config (appId, webDir, plugins)
├── src/haptics.ts          # Haptics abstraction (native + web fallback)
├── src/App.tsx             # Main app — uses haptics.ts throughout
├── vite.config.ts          # base: './' required for Capacitor
├── index.html              # viewport-fit=cover for notch/island support
├── server.ts               # WebSocket + webhook backend (deploy to Railway)
└── ios/                    # Generated by `npx cap add ios` (git-ignored)
└── android/                # Generated by `npx cap add android` (git-ignored)
```
